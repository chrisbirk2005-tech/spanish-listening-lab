How to connect your own sheet

In Google Sheets, select File → Share → Publish to web, choose the Vocabulary tab and Comma-separated values (.csv). Publish and paste that generated URL above. The published feed is viewable by anyone with the feed URL, so keep private information out of this sheet. This page reads the published data; it cannot edit the spreadsheet. If direct fetching fails, download CSV from Sheets and import using the file selector. The app will try to refresh every 60 seconds while the page is open, but publication and caching can delay changes. Keep a stable word in column A and your exact personal definition in B. Columns C–F: mnemonic, example, source, Active (set to 'no' to exclude).

Offline sample mode works without a connection. Review history and URL are kept in your browser's local storage, not synchronized across devices. Keep this HTML file in a consistent location and browser to retain that history. Your spreadsheet remains the source of truth for vocabulary.
